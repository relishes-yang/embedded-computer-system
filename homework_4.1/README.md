# Python编程实验

## 📋 实验概述
本仓库包含5个Python基础编程实验，涵盖字符串处理、排序算法、数列生成、数据结构设计等核心概念。

## 🚀 运行环境
- Python 3.8+
- 无特殊依赖

## 📂 文件结构
- `test1.py` - 九九乘法表
- `test2.py` - 字符串索引查找
- `test3.py` - 多级排序程序
- `test4.py` - 斐波那契数列扩展
- `test5.py` - 一词多义字典

## ▶️ 运行方法
```bash
# 运行单个实验
python experiment1_multiplication_table.py

# 运行所有实验
python run_all.py
